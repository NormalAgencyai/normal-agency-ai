موقع نورمال — طريقة الرفع على GitHub
====================================
1) فكّ ضغط الملف normal-site.zip على جهازك.
2) ارفع كل محتويات المجلد إلى جذر المستودع (وليس المجلد نفسه): index.html و style.css و script.js و works.js
   وصور اللوغو الأربع، والمجلدان images و videos.
3) انتظر دقيقة ثم افتح الموقع (Ctrl+F5 لتحديث الصفحة).
ملاحظة: إن رفعت الصور والفيديوهات في الجذر مباشرة بلا مجلدات فالموقع يجدها أيضًا.

إدارة الأعمال: افتح الموقع بإضافة #owner في آخر الرابط، عدّل ثم انسخ works.js والصقه في GitHub.
لإضافة شخصين: Settings ← Collaborators ← Add people، وفعّل التحقق بخطوتين.
